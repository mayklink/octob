# Octob v1.0.166

Data de lançamento: 9 de agosto de 2026

Commit: `549b835`

Tag: `v1.0.166`

## Resumo

A versão 1.0.166 reposiciona o Octob como um workspace desktop focado em repositórios Git, worktrees e sessões de programação com IA.

Esta atualização reduz significativamente o escopo do produto, remove funcionalidades paralelas que aumentavam sua complexidade e simplifica a navegação. Ao mesmo tempo, preserva os recursos centrais para trabalhar com diferentes CLIs, Connections, arquivos, terminal, Git, pull requests e servidores MCP.

## Destaques

### Octob mais enxuto

O aplicativo agora se concentra em:

- projetos e repositórios Git;
- branches e worktrees isoladas;
- Connections para trabalhar com múltiplos repositórios;
- sessões paralelas com agentes de IA;
- terminal integrado;
- arquivos, busca, Git, diffs e comentários;
- criação e revisão manual de pull requests;
- ferramentas externas por servidores MCP.

Foram removidas aproximadamente 28 mil linhas de código que sustentavam funcionalidades fora desse núcleo.

### Escolha da CLI ao criar uma sessão

O botão `+` da barra de sessões voltou a permitir a escolha da CLI antes da criação da sessão.

As opções são exibidas conforme as ferramentas detectadas no computador:

- OpenCode;
- Claude Code;
- Codex;
- Mistral Vibe;
- Cursor CLI;
- Google Antigravity;
- terminal manual.

O mesmo seletor funciona em worktrees e Connections.

### MCP configurável por repositório

Os servidores MCP cadastrados formam um catálogo global, mas cada projeto escolhe individualmente quais servidores utiliza.

- A seleção fica disponível na barra de sessões.
- Novas sessões recebem somente os MCPs selecionados para o projeto.
- Connections recebem a união dos MCPs configurados nos projetos conectados.
- Projetos existentes herdam inicialmente todos os MCPs globais habilitados até que sua seleção seja personalizada.
- A configuração é aplicada a Codex, Claude Code, Cursor CLI e Mistral Vibe.

Alterações de MCP afetam novas sessões. Uma sessão já iniciada precisa ser recriada para receber uma configuração diferente.

### Preferência de exibição simplificada

Os antigos nomes **Basic** e **Advanced** foram substituídos por uma preferência de exibição mais direta:

- **Visão geral:** cards de projetos, Connections e worktrees;
- **Compacta:** navegação direta pela barra lateral.

A preferência pode ser alterada pelo cabeçalho ou em **Configurações → Geral → Exibição**. Ao escolher a visualização Compacta, a barra lateral é aberta automaticamente.

### Connections na Visão geral

Os worktrees pertencentes a uma Connection agora são carregados corretamente na Visão geral. Seus cards podem ser selecionados para abrir o projeto e o worktree correspondentes.

## Funcionalidades removidas

Esta versão remove definitivamente:

- Board e Kanban;
- tickets internos e dependências entre tickets;
- Board Assistant;
- importação de tickets do GitHub, Jira e Azure DevOps;
- PR Inbox;
- revisão automática de pull requests;
- anexos específicos de tickets e comentários de PR;
- pet de desktop;
- serviços, handlers IPC, stores, tipos, traduções e configurações exclusivos desses recursos.

A criação e revisão manual de pull requests continuam disponíveis como parte do fluxo Git principal.

## Banco de dados e atualização

Não há migration de conversão ou exclusão de dados nesta versão.

- Instalações novas não criam as estruturas removidas.
- Bancos existentes podem conservar tabelas antigas fisicamente no arquivo SQLite.
- O Octob 1.0.166 não acessa nem utiliza essas tabelas legadas.
- Projetos, worktrees, Connections, sessões e configurações centrais permanecem disponíveis.

Como precaução, usuários que desejarem manter uma cópia integral do estado anterior podem salvar o diretório `~/.octob` antes de atualizar.

## Impacto para usuários

Esta é uma atualização de simplificação com remoção intencional de funcionalidades. Usuários que dependiam do Board, tickets, PR Inbox, revisão automática ou pet não encontrarão mais essas áreas no aplicativo.

Os fluxos de desenvolvimento baseados em projetos, worktrees, Connections, sessões de IA, terminal, Git, arquivos e MCP continuam sendo o caminho principal do produto.

## Compatibilidade

- Windows, macOS e Linux;
- OpenCode;
- Claude Code;
- Codex;
- Mistral Vibe;
- Cursor CLI;
- Google Antigravity;
- modo de terminal manual.

A disponibilidade de cada agente depende da respectiva CLI estar instalada e autenticada.
